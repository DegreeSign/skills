Why this exists

Prompts drift. Procedures do not.

A one-off prompt works once. A skill is a checked-in procedure the agent loads only when the task matches, so the same job runs the same way next month.

01

No context tax.

The agent reads a name and a description until a task matches, then loads one sub-skill. The rest stays out of the window.

02

Nothing in your app.

The package is Markdown, JSON and a few optional Node scripts. It adds no service, no account and no build step to the project you are building.

03

Pinned and auditable.

Clone a tag, read every instruction and run the map checker. MIT licensed, no account, no telemetry, no hidden service.

Straight talk.

This is not an SDK, and it does not run your code. It gives a compatible agent a procedure to follow; an agent that does not read skills gets nothing. The installer edits OpenCode and Claude Code settings only, and only after you accept. The icon rasterizer may fall back to downloading sharp-cli when the machine has no local renderer.

FAQ

The questions you are about to ask.

Answer what the page does not already answer. No jargon, no asterisks and no marketing hedging.

Which agents can use it?

Any agent that discovers skills from a skills directory such as .agents/skills/, .claude/skills/ or .opencode/skills/, project or global. The installer defaults to ~/.agents/skills and only edits OpenCode and Claude Code settings.

Does it run code or add dependencies?

No. The skills are Markdown and JSON, and nothing is installed into your app. Optional Node helpers for icon rasterization, the map check and the llms check run only when a skill invokes them.

Does it need an account or a server?

No account, no server and no telemetry. The only network calls are the sources a skill documents and the optional update check, which asks the npm registry at most once every 24 hours.

How do I update it?

Re-run npx @degreesign/skills. It replaces the folder it owns. The bundled check compares the installed marker with the registry once a day and prints an update command; the agent asks before updating.

Can I pin a version?

Yes. Clone the v2.2.1 tag and run node bin/install.mjs, or install a pinned npm version.

What does it not do?

It does not write your app, run your code or guarantee a result. It gives a compatible agent a procedure; an agent that does not read skills gets nothing.
